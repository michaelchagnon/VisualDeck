Install

  1. Download {{ release.filename }} with the button above. It comes from the VisualDeck release on GitHub.
  2. Run it. It installs for your Windows user only and adds a Start menu entry, a desktop shortcut and an uninstaller. At the end it offers to start VisualDeck.
  3. If Windows SmartScreen says it protected your PC from an unrecognized app, choose More info, then Run anyway. The installer isn't code-signed yet; the checksum below is how to make sure the file is the one published here.

Then follow Getting started, or the quick start if you're running a show someone else built.

Uninstall

Use Windows Settings › Apps, or Start › VisualDeck › Uninstall VisualDeck. Your shows and settings are kept.
